# LAB 001 — Analisador de Operações

Primeiro projeto real.

## Objetivo

Ler um CSV e produzir:
- financeiro por operação;
- financeiro total;
- quantidade de operações;
- financeiro por ativo.

## Evolução

1. csv.DictReader
2. conversão de tipos
3. função
4. acumuladores
5. agrupamento
6. testes
7. tratamento de erros
8. refatoração para Pandas

## Desafios

- maior operação;
- menor operação;
- financeiro por lado;
- validação de campos;
- relatório CSV.
