## 4. Prática guiada

### A — Reproduza
Refaça sem copiar.

### B — Modifique
Mude entradas, nomes ou condições.

### C — Generalize
Transforme a lógica em componente reutilizável.

### D — Quebre
Crie uma entrada inválida.

### E — Corrija
Explique a causa antes de alterar o código.

## 5. Exercício

## 6. Desafio

Resolva uma variação sem consultar solução. Se precisar de IA, peça uma pista.

## 7. Erros comuns

- copiar código sem entender;
- ignorar tipos;
- não validar entradas;
- não testar casos extremos;
- misturar regra de negócio com apresentação;
- usar bibliotecas sem entender o conceito.

## 8. Claude Code

Use como professor:

> Não escreva a solução. Explique meu erro e faça perguntas para eu descobrir.

Depois:

> Revise meu código procurando bugs, testes ausentes e problemas de organização. Não reescreva tudo.
