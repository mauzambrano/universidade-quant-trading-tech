# 🎓 Universidade Quant/Trading Tech

## Formação completa — do Backoffice ao Quant/Trading Tech

Uma formação prática e progressiva para sair do básico de programação e chegar à arquitetura de um **Trading System**.

> **Não é um banco de perguntas e respostas.** Cada aula ensina o conceito, conecta com o mercado financeiro, mostra exemplos, guia a prática, propõe exercícios e desafios, documenta erros e gera um artefato que entra no projeto acumulativo.

### Método

**Conceito → Mercado → Exemplo → Prática guiada → Exercício → Desafio → Erros → Claude Code → Obsidian → Artefato → Projeto**

A regra é simples:

> **Não avance porque leu. Avance porque conseguiu fazer e explicar.**
